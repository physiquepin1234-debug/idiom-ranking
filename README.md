# 전국 관용표현 랭킹전

초등학생이 관용표현의 앞부분(A)과 뒷부분(B)을 선으로 이어 맞히는 1분 타임어택 학습 게임입니다.

## 접속 주소
**https://physiquepin1234-debug.github.io/idiom-ranking/**
(수정 후 `GitHub 올리기.bat` 실행 → 1~10분 뒤 반영)

## 실행 방법 (내 PC에서 시험)
- **`테스트 서버 실행.bat`** 을 더블클릭하면 브라우저에서 `http://localhost:8080` 이 열립니다.
  (검은 창을 닫으면 서버가 꺼집니다.)

## 문제 바꾸기
1. `data\questions.xlsx` 를 엑셀로 엽니다.
   A열 앞부분 | B열 뒷부분 | C열 완성된 표현 | D열 의미 (1행부터 바로 문제)
2. 저장한 뒤 **`문제 업데이트.bat`** 을 더블클릭합니다. → `js\idioms-data.js` 가 새로 만들어집니다.

## 폴더 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 첫 페이지 |
| `css/style.css` | 화면 꾸미기 |
| `css/game.css` | 게임 화면 (사이버 네온 스타일) |
| `js/app.js` | 화면 전환과 각 화면(시작, 설정, 게임방법, 연습, 결과, 랭킹 3종) |
| `js/game.js` | 게임 진행: 흩어진 배치, 선 긋기(드래그/톡톡), 1분 타이머, 점수·콤보 |
| `js/sound.js` | 효과음 (코드로 합성, 소리 파일 없음) |
| `js/idioms.js` | 라운드 문제 뽑기(정답이 2개 생기는 조합은 함께 내지 않음), 신체 부위 분류 |
| `js/ranking.js` | 전국·학교·반별 순위 계산 (학교 순위는 5명 이상 참가한 학교만) |
| `js/store.js` | 저장소: 프로필·도전 기록은 이 기기, 학생별 최고 기록·학교 합계는 Firebase |
| `js/firebase-config.js` | Firebase 웹 앱 설정값 |
| `firestore.rules` | Firestore 보안 규칙 (콘솔 > Firestore > 규칙 탭에 붙여넣고 게시) |
| `js/idioms-data.js` | 문제 데이터 (자동 생성) |
| `js/schools-data.js` | 전국 초등학교 6,330개 (NEIS, 자동 생성) |
| `tools/` | 문제·학교 목록 변환, 테스트 서버 스크립트 |

## 점수 규칙 (`js/game.js` 맨 위 `SCORE` 에서 바꿀 수 있음)
- 정답 +10, 콤보 보너스 +5 × (콤보−1), 오답 −3(콤보 초기화), 10개 모두 이으면 +20 후 새 문제
- 제한 시간 60초 (`TIME_LIMIT`)

## 학교 목록 다시 받기
`학교목록 업데이트.bat` 을 실행하고 NEIS 인증키를 입력합니다. (키는 파일에 저장되지 않습니다)

## 진행 상황
- [x] 1단계: 화면 목록 (시작 화면, 게임방법, 연습모드, 게임 화면, 명예의 전당, 우리 학교 랭킹, 개인별 랭킹, 학교·닉네임 설정)
- [x] 2단계: 게임 규칙 (선 긋기, 1분 타이머, 점수, 콤보, 효과음, 연습 게임, 결과 복습)
- [x] 3단계: 전국 초등학교 목록 넣기
- [x] 4단계: 온라인 전국 랭킹 (Firebase)
- [x] 인터넷 배포 (GitHub Pages)

## Firebase 데이터 구조
- `players/{학생ID}`: 닉네임, 학교, 학년·반, 최고 점수, 도전 횟수 (전국·학교 순위용)
- `schools/{학교코드}`: 참가 학생 수, 최고 점수 합계·평균 (학교 순위용)
- `records/{자동ID}`: 모든 게임 기록 (학생은 추가만 가능, 조회는 나중에 관리 화면에서)
- 같은 태블릿을 여러 학생이 쓰면 설정 화면의 **"다른 학생이에요"** 로 새로 등록합니다.
- [ ] 5단계: 디자인 다듬기와 인터넷 배포
